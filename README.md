# PRAXIS — The Intern Hub

A responsive single-page internship discovery landing page designed for GitHub Pages.

## Included
- Cinematic dark hero inspired by the supplied reference image
- PRAXIS — The Intern Hub branding
- Google / Apple / Email login UI
- Country selector containing countries worldwide
- Location filter: Remote, Work from home, On-site, Hybrid
- Domain filter: UI/UX, AI/ML, Software, Data Science, Cybersecurity, etc.
- Quick filter chips
- Responsive internship cards
- Smooth scrolling and small UI interactions
- No framework or build step required

## Run locally
Just open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/ (root)**.
6. Save.

The login buttons are UI placeholders. To make real Google/Apple/email authentication work, connect them to an authentication provider such as Firebase, Supabase Auth, Auth0, or your own backend.
